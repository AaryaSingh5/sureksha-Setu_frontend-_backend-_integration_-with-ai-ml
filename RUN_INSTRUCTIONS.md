# How to Run Suraksha Setu (Tourist Safety App)

## 1. Prerequisites
Ensure you have the following installed on your system:
- **Node.js** (v18 or higher recommended)
- **npm** (comes installed with Node.js)

## 2. Navigate to the Project Directory
The project code is located in the `suraksha-setu (2)` folder. 
Open your terminal and navigate to it:
```bash
cd "/Users/jahnvee/Documents/SOS/suraksha-setu (2)"
```

## 3. Install Dependencies
If you haven't already, install the required packages using npm:
```bash
npm install
```

## 4. Start the Development Server
Run the following command to start the React development server:
```bash
npm run dev
```

## 5. View the App in your Browser
Once the server starts, you will see an output like this:
```
  VITE v6.4.3  ready in 494 ms

  ➜  Local:   http://localhost:3001/
```
Open your web browser and go to the Local URL provided (e.g., `http://localhost:3001/`).

---

### Troubleshooting
- **Missing script "dev" error**: This means you ran the command in the wrong folder. Make sure you are exactly in the `/Users/jahnvee/Documents/SOS/suraksha-setu (2)` directory.
- **Port in use**: Vite will automatically find the next available port (e.g., 3001, 3002). Just use the link printed in your terminal.
